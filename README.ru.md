# galIMV

Десктопная галерея изображений и инспектор метаданных для медиафайлов, созданных нейросетями. Приложение разработано на C++20 и Qt 6.8 (QML). Поддерживает многопоточное кэширование миниатюр, поиск по тегам Danbooru, разбор параметров генерации, тему Lobe и 20 языков интерфейса.

![Интерфейс галереи и инспектора galIMV](docs/screenshots/galimv_main.png)

## Основные возможности

### Многопоточный движок галереи
- Асинхронное сканирование папок и фоновая генерация миниатюр.
- Виртуализированная masonry-сетка с плавным скроллингом больших коллекций изображений.
- Сортировка по дате, имени файла, разрешению и размеру на диске.
- Группировка по подпапкам, модели генерации или дате изменения.
- Множественный выбор файлов для пакетных операций.

### Извлечение метаданных генерации
- **Stable Diffusion (Automatic1111, WebUI Forge, SD.Next)**: позитивный и негативный промпты, сид, сэмплер, количество шагов, шкала CFG, чекпоинт модели, хэш, сила денойза, теги LoRA и clip skip.
- **ComfyUI**: рекурсивный разбор графа выполнения, нод промптов, загрузчиков чекпоинтов и параметров сэмплера.
- **NovelAI и Fooocus**: извлечение параметров из встроенных структур JSON и текстовых чанков PNG.
- **Midjourney**: извлечение промпта и структурирование параметров.

### Поиск по тегам Danbooru
- Быстрый автокомплит тегов на базе предварительно индексированного словаря частотности.
- Категоризация тегов по бейджам (автор, персонаж, франшиза, общие).
- Фильтрация галереи по тегам в реальном времени.

### Интерфейс и оформление
- **Тема Lobe**: темный и светлый режимы с 6 вариантами цветовых акцентов.
- **Векторные иконки Tabler**: четкая SVG-графика для любых экранов и масштабов DPI.
- **Сохранение настроек**: выбранная тема, цвет акцента, язык интерфейса и параметры сетки сохраняются между запусками.

## Сборка из исходного кода

### Требования
- CMake 3.21 или новее
- Компилятор с поддержкой C++20: MinGW-w64 (GCC 13+) или MSVC 2022
- Qt 6.8+ (модули: `Core`, `Gui`, `Quick`, `Qml`, `Widgets`, `Svg`, `Concurrent`)
- Система сборки Ninja
- *(Опционально)* Inno Setup 6 для создания установочного пакета Windows
- *(Опционально)* 7-Zip для упаковки портативных архивов

### Инструкция по сборке
```bash
git clone https://github.com/your-username/galIMV.git
cd galIMV

# Конфигурация CMake
cmake -B build -S . -G "Ninja" -DCMAKE_BUILD_TYPE=Release

# Сборка проекта
cmake --build build --config Release

# Установка исполняемых файлов и рантайма Qt
cmake --install build --prefix dist
```

### Запуск приложения
Запуск через встроенный командный файл:
```cmd
run.bat
```

### Создание релизных пакетов
Сборка портативных архивов и инсталлятора Inno Setup:
```cmd
package.bat
```

## Структура проекта

```
galIMV/
├── CMakeLists.txt              # Конфигурация сборки CMake
├── package.bat                 # Скрипт автоматической сборки релизных пакетов
├── run.bat                     # Скрипт запуска приложения
├── src/                        # Исходный код на C++
│   ├── gallery_model.cpp/h     # Модель галереи и кэш миниатюр
│   ├── metadata_reader.cpp/h   # Парсер метаданных генерации
│   ├── tag_autocomplete.cpp/h  # Автокомплит и поиск по словарю тегов Danbooru
│   ├── launcher.cpp            # Легковесный загрузчик для Windows
│   └── main.cpp                # Точка входа в приложение
├── qml/                        # Интерфейс на Qt Quick / QML
│   └── main.qml                # Главное окно галереи и инспектора
├── locales/                    # Файлы локализаций JSON
├── resources/                  # Иконки приложения, SVG и ресурсы
├── installer/                  # Скрипт установщика Inno Setup (setup.iss)
├── docs/
│   └── screenshots/            # Скриншоты интерфейса
└── tests/                      # Модульные и регрессионные тесты
```
